Overview

Bahar Autonomous Evolution AI is my own research platform: an attempt to build an AI that does not merely answer, but accumulates — learning language, skills and corrections over time, inside strict safety boundaries. It is a private, long-horizon R&D project, and I document its state honestly: parts are proven, parts are scaffolding, and nothing is promoted without evidence.

The platform is organized as nine modules: a model brain (Qwen2.5-7B-Instruct behind a standard interface), an agent harness for planning, tool dispatch and verification, a research engine, permanent memory, a reflection and error-learning loop, an autonomous coding sandbox, a skill registry, a training engine, and a self-improvement controller that schedules evaluation and enforces promotion and rollback decisions. The local prototype already implements the memory system — SQLite-backed, with versioned corrections, soft deletion and a mutation audit trail — and the agent harness proof of concept, built on LangChain Deep Agents with LangGraph checkpointing, passed its tests including restart persistence.

The model track fine-tunes Qwen with QLoRA for Bangla and Banglish first — language before domain — using public datasets on a single T4 GPU. Training has been genuinely hard: two runs diverged late, and the current recipe — lower learning rate, early checkpoints, held-out evaluation against the original baseline — is the direct product of those failures. The boundaries are non-negotiable: the AI holds its own scoped identity and never inherits my credentials, takes no customer data into training, and a candidate model is adopted only after outperforming the baseline without serious regression.

What it includes

  • Nine-module architecture — brain, harness, research, memory, reflection, sandbox, skills, training, controller
  • Permanent memory — SQLite-backed, versioned corrections, soft delete, full mutation audit trail
  • Agent harness POC — LangChain Deep Agents + LangGraph checkpoints; 13/13 tests passed incl. restart persistence
  • QLoRA fine-tuning — Qwen2.5-7B for Bangla & Banglish on public datasets
  • Evaluation & promotion gates — a model ships only after beating the baseline
  • Safety boundaries — own scoped identity, no customer data in training
